# Filing Guide

| Information | Store in |
|---|---|
| New idea | 00 Inbox |
| Ongoing responsibility | 10 Areas |
| Temporary goal | 20 Projects |
| External reference | 30 Resources |
| Evergreen knowledge | 40 Knowledge |
| Daily thoughts | 50 Journal |
| AI generated summary | 90 AI |

Rule of thumb:
If you created or synthesized the knowledge, it usually belongs in **40 Knowledge**.
If you are merely collecting it, it belongs in **30 Resources**.
