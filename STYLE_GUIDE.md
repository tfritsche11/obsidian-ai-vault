# Style Guide

## Naming
- Use descriptive singular note names.
- Prefer `Brother MFC-L2827DW` over `Printers`.
- One concept per note.

## Linking
- Prefer `[[Wiki Links]]` over plain text.
- Link people, projects, hardware, services and concepts.

## Tags
Use only broad categories:
- #health
- #family
- #career
- #hardware
- #software
- #recipe
- #book

## Metadata
Keep front matter minimal and consistent.
