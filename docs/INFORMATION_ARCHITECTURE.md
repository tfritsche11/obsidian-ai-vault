# Information Architecture

## Rule 1
One note = one primary subject.

## Rule 2
Prefer links over duplicate text.

## Rule 3
Areas are long-lived responsibilities.
Projects have an end.

## Rule 4
Resources are reference material you consume.
Knowledge contains your own curated understanding.

## Rule 5
AI-generated content always lives in `90 AI/`.

## Rule 6
Use the appropriate template. All templates follow OKF v0.2 document conventions.
